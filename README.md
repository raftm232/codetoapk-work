# FFS Tool — Web + Android

مشروع يجمع نسخة ويب ثابتة ونسخة Android مبنية بـ Kotlin لمعالجة ملفات FFSZ و0x457 وXXTEA/Base64 وأرشيفات ZIP.

## 1) نشر نسخة الويب على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **محتويات هذا المجلد** إلى الفرع `main` (لا ترفع ملف ZIP نفسه فقط).
3. افتح `Settings → Pages`، واختر `GitHub Actions` كمصدر النشر.
4. من تبويب `Actions` شغّل `Deploy Web Version to GitHub Pages` أو ادفع تعديلًا داخل مجلد `web/`.
5. بعد نجاح العملية سيظهر رابط الموقع في تشغيل الـ workflow وفي `Settings → Pages`، غالبًا بالشكل `https://USERNAME.github.io/REPOSITORY/`.

الموقع موجود في `web/index.html` ويستخدم مكتبات من CDN؛ يلزم اتصال بالإنترنت لتحميلها. الملفات التي تختارها تتم معالجتها محليًا داخل المتصفح.

## 2) بناء APK قابل للتثبيت

1. ارفع المشروع كاملًا إلى GitHub.
2. افتح تبويب `Actions` وشغّل `Build Android APK` يدويًا، أو ادفع تعديلًا على ملفات Android.
3. بعد نجاح البناء افتح تشغيل الـ workflow، وانزل إلى `Artifacts`، ثم نزّل `FFS-Tool-debug-apk` وفك ضغطه.
4. ثبّت ملف APK الناتج على جهاز Android. هذه نسخة **debug** للتجربة والتثبيت، وليست إصدارًا موقّعًا للنشر على Google Play.

## تنبيه مهم بخصوص ميزة تحويل ملفات إلى APK

بناء تطبيق Android نفسه عبر GitHub Actions ينتج APK حقيقيًا قابلًا للتثبيت. أما دالة `ApkConverter` الموجودة في المصدر الأصلي فتكوّن ملف ZIP به ترويسة وملفات توقيع شكلية؛ هذا لا يكفي لصنع تطبيق Android صالح للتثبيت. لا تعتبر الملفات التي تنتجها تلك الميزة تطبيقات APK حقيقية. يلزم تحويل ملفات المصدر إلى مشروع Android صالح ثم بناؤه باستخدام Android Gradle Plugin وبيانات Manifest والموارد والتوقيع الصحيح.

## حدود نسخة الويب

واجهة الويب تنفّذ FFSZ و0x457 وXXTEA/Base64، وتتعامل مع ملفات ZIP مع إبقاء أسماء ومسارات الملفات الداخلية. لأن اختلافات تنسيق ملفات الألعاب واردة، اختبر على نسخ احتياطية أولًا. المكتبات تُحمّل من CDN.

## ملاحظات أمان

- لا تضع مفاتيح API أو كلمات مرور في مستودع عام.
- ملف `.env` غير مرفق عمدًا؛ لا ترفع أسرارًا إلى GitHub.
- اختبر النتائج على ملفات غير مهمة قبل استخدام الأداة على ملفات أصلية.


## تغيير رابط Telegram
ابحث في الملفين `web/index.html` و`app/src/main/java/com/example/ui/MainScreen.kt` عن `PUT_YOUR_USERNAME_HERE` واستبدله باسم مستخدم قناتك أو مجموعتك في Telegram (من دون @). مثال: `https://t.me/mychannel`. ارفع التعديلات إلى GitHub ثم أعد نشر Pages وأعد بناء APK من Actions.
